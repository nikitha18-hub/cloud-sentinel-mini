    04 / Know the boundaries

    Built to teach, not to connect

    CloudSentinel Mini is a local learning prototype. It never accesses real infrastructure.

    Limitations

    • Uses only five simulated boolean settings
    • No live AWS or other cloud-provider connection
    • No CloudTrail, IAM policy, or network discovery
    • Demo score is not a compliance or security rating

    Future scope

    • Read-only AWS integration with explicit consent
    • CloudTrail event and IAM policy analysis
    • Multi-cloud configuration support
    • Continuous monitoring and change history
